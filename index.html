Tentang Saya

Fondasi Rekayasa Internet & Minat Backend Web

Saya adalah mahasiswa Teknik Rekayasa Internet di Politeknik Elektronika Negeri Surabaya (PENS) yang berfokus pada pengembangan sistem backend web dan integrasi embedded web server. Berawal dari latar belakang rekayasa internet dan sistem terbenam, saya terbiasa memahami bagaimana data mengalir dari sensor perangkat keras hingga diproses dan disimpan secara andal oleh server.

Dalam pengembangan web, saya memilih mendalami fondasi arsitektur perangkat lunak dengan membangun aplikasi PHP berbasis arsitektur MVC dan sistem router mandiri tanpa bergantung pada framework pihak ketiga. Fokus utama saya adalah memastikan alur logika server terstruktur, mengoptimalkan interaksi database MySQL menggunakan prepared statements, serta menerapkan praktik keamanan dasar seperti pencegahan IDOR, pengamanan sesi, dan autentikasi bertingkat.

03. Portofolio

Proyek Unggulan

Studi kasus nyata yang menunjukkan implementasi arsitektur backend, penanganan keamanan, dan integrasi embedded server.

★ Proyek Utama Backend Aplikasi Organisasi Kampus

Sistem E-Voting Kampus Berbasis Custom PHP MVC

Peran Saya: Backend Developer & Database Designer

Aplikasi web pemilihan suara digital untuk kebutuhan organisasi himpunan mahasiswa. Dirancang dari nol dengan arsitektur Model-View-Controller (MVC) dan router mandiri tanpa framework pihak ketiga untuk memastikan kontrol penuh terhadap alur data dan keamanan.

Tantangan / Problem:

Kebutuhan sistem pemilihan suara yang memiliki verifikasi berjenjang agar terbebas dari manipulasi, mampu memproses ribuan data pemilih sekaligus, dan tahan terhadap manipulasi parameter akses publik.

Solusi Teknis:

Membangun sistem autentikasi admin berjenjang ("dua kunci"), pemrosesan file Excel menggunakan PhpSpreadsheet, pencetakan bukti suara digital via FPDF, serta audit keamanan database menyeluruh.

Penerapan & Perbaikan Keamanan Sistem:

  • Mitigasi SQL Injection: Mengganti seluruh query SQL mentah menggunakan prepared statements via ekstensi mysqli.
  • Perbaikan Celah IDOR: Mengamankan proses verifikasi hak unduh berkas PDF bukti suara dari manipulasi ID pemilih.
  • Perlindungan Rute & Sesi: Menutup rute internal yang terbuka dengan middleware pengecekan otorisasi login dan penanganan session timeout.
  • Isolasi Kredensial: Memisahkan parameter koneksi database ke berkas .env yang tidak dapat diakses secara publik.
  • Restrukturisasi Skema: Memperbaiki dan merapikan integritas relasi tabel pada database/schema.sql.

Teknologi yang Digunakan

PHP (Native MVC) MySQL mysqli PhpSpreadsheet FPDF .env Laragon

Hasil Implementasi

Berhasil digunakan pada pemungutan suara pemilihan umum himpunan kampus, mencatatkan proses import data pemilih tanpa duplikasi dan proses audit suara yang terverifikasi.

Sebelum (Rentan SQL Injection)

Sesudah (Aman dengan Prepared Statement)

$stmt = $db->prepare("SELECT id, nim, has_voted FROM voters WHERE nim = ?");
$stmt->bind_param("s", $nim);
$stmt->execute();
$voter = $stmt->get_result()->fetch_assoc();
Embedded Web Server & IoT Proyek Praktikum & Hardware

Embedded Web Server & Controller Running Text ESP32

Peran Saya: Perancangan Sistem, Wiring Hardware, dan Pemrograman Firmware (End-to-End)

Sistem kendali perangkat IoT yang menggabungkan embedded HTTP server pada ESP32 dengan modul LED Dot Matrix 8x8 dan sensor ultrasonik. Halaman web pemutar lagu disimpan dan disajikan langsung dari memori ESP32, dengan sinkronisasi teks lirik dan interaksi sensor jarak.

Tantangan:

Menyajikan halaman web mandiri dari mikrokontroler dengan keterbatasan memori (RAM), sekaligus mengontrol display matrix secara *real-time* tanpa membuat respon audio atau sensor mengalami *stutter*.

Solusi Teknis:

Mengoptimalkan alokasi buffer HTTP server di ESP32, merancang alur logika pembacaan jarak sensor ultrasonik, dan memprogram sinkronisasi running text lirik lagu saat pemutaran aktif.

Fitur & Karakteristik Utama:

  • Embedded Web Server: Web pemutar musik disajikan langsung dari ESP32 tanpa perantara web server eksternal.
  • Sinkronisasi Teks & Audio: Menampilkan potongan lirik dari 2 lagu pada LED Dot Matrix 8x8 saat musik diputar di web.
  • Pemicu Interaktif Sensor Ultrasonik: Saat mendeteksi objek mendekat pada jarak tertentu, display menampilkan teks responsif "oke bos".
  • Evolusi Desain: Rancangan awal menggunakan potensiometer berevolusi menjadi kontrol berbasis web dan sensor otomatis.

Teknologi Hardware & Software
